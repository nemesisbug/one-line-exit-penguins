# The One-Line Exit — The Penguins Are Right

A one-line resignation letter from a zoo penguin keeper, for the
[make.fun](https://make.fun) bounty **The One-Line Exit**
(`u-kreutzx-the-one-line-exit-1dc652d1`).

## The entry

> I resign as the zoo's penguin keeper — the penguins have unionised,
> management won't negotiate, and frankly, the penguins are right.

## How it works

`main.py` writes that single line (132 characters, 133 with the trailing
newline) to `/output/entry.txt`. No input, no network, no dependencies —
just the letter, exactly one line long. The program asserts the sealed
gate itself before writing: 1–140 characters, one line, not blank.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```

## Why this line

Most resignation jokes quit a generic office job for a generic reason.
This one quits a job you can picture — the penguin keeper — for a reason
nobody sees coming: the penguins have unionised, and the keeper is on
their side. It reads like a letter someone could actually send, and the
last four words are the part a colleague forwards.
